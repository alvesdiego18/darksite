Como a Inversão Inteligente Elimina a Fadiga Visual na Web

Publicado por Diego Alves • Tempo de leitura: 4 min

Ao navegar pela web durante a madrugada, fundos 100% brancos emitem um brilho agressivo que sobrecarrega a retina. Extensões de inversão comum simplesmente invertem todas as cores em 180°, transformando fotos de pessoas em negativos assustadores e gráficos em tons bizarros.

Com o Smart Dark Mode, cada elemento HTML é avaliado dinamicamente. Os tons de fundo são mapeados para uma paleta escura harmônica, enquanto mídias e fotos permanecem completamente intocadas.

// WCAG Relative Luminance Check function getLuminance(r, g, b) { const [rs, gs, bs] = [r, g, b].map(c => { c = c / 255; return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4); }); return 0.2126 * rs + 0.7152 * gs + 0.0722 * bs; }

Engenharia Sob Medida

Por que o DarkSite é diferente de outros temas?

Criado com foco em fidelidade visual, baixo consumo de bateria e respeito total às diretrizes de acessibilidade.

Zero Flash de Branco

Injeção no ciclo de vida document_start pelo Service Worker via chrome.scripting.registerContentScripts. A página já nasce escura antes mesmo do navegador renderizar a primeira camada.

#document_start

Preservação Real de Mídias

Fotos, ilustrações, vídeos, SVGs vetoriais e elementos canvas jamais têm suas cores invertidas. Você vê as fotos exatamente como foram tiradas e os vídeos com suas cores autênticas.

<img> <video> <canvas>

Contraste Dinâmico WCAG

Cálculo matemático de luminância relativa em tempo real. Garante que textos pequenos alcancem a proporção mínima de 4.5:1 exigida pelas normas internacionais de ergonomia e acessibilidade.

WCAG 2.1 AA/AAA

Shadow DOM & Web Components

Patch não-intrusivo em Element.prototype.attachShadow no contexto do mundo principal. Permite que o motor descubra e estilize árvores de Shadow DOM mesmo criadas tardiamente por frameworks modernos.

attachShadow patch

Controle Fino em Tempo Real

Ajuste contraste (70%–130%), brilho (60%–110%) e calor de cor através do filtro sépia (0%–40%) para relaxamento dos olhos antes de dormir, além de desfoque suave de carregamento.

chrome.storage sync

// 1. background.js (Service Worker) await chrome.scripting.registerContentScripts([{ id: 'sdm-base-css', css: ['dark-theme.css'], runAt: 'document_start', matches: ['<all_urls>'] }]); // 2. main-world.js (Shadow DOM Hook) Element.prototype.attachShadow = function(init) { const root = original.call(this, init); this.setAttribute('data-sdm-host', ''); return root; };

Perguntas Frequentes

Dúvidas Comuns

A extensão envia meus dados de navegação para algum servidor?
Não! O DarkSite é 100% privado e opera totalmente offline dentro do seu próprio navegador. Suas preferências de brilho, contraste e sites ignorados são armazenadas estritamente no seu computador através da API chrome.storage.local. Não há nenhum serviço de telemetria ou rastreamento.
Como o DarkSite evita o "flash de luz branca" ao abrir novas abas?
Extensões convencionais esperam a página carregar (document_idle) para aplicar estilos, o que resulta na tela branca ofuscante. O DarkSite utiliza a API chrome.scripting.registerContentScripts para registrar a folha de estilo escura antes do HTML ser interpretado (document_start), garantindo que a base escura esteja ativa na pintura zero.
Por que imagens e vídeos não ficam invertidos como em outras extensões?
Em vez de aplicar um filtro de CSS filter: invert(1) indiscriminado na tag <html>, o motor do DarkSite analisa árvore por árvore. Tags como <img>, <video>, <picture>, <canvas> e <svg> são preservadas intocadas.
Posso desativar a extensão apenas em um site específico?
Sim! Basta abrir o popup da extensão e clicar no botão "Não aplicar neste site". O domínio é adicionado instantaneamente à sua lista de exclusão (Blacklist), e você também pode pesquisar e gerenciar todos os sites ignorados no painel de configurações.
